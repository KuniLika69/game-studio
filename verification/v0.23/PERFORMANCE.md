# Производительность 0.23 RC

Замеры локального кандидата проведены на Windows 11 Pro 26300, AMD Ryzen 9 9950X, NVIDIA GeForce RTX 4090 (24 ГБ VRAM, драйвер 610.88) и 64 ГБ ОЗУ. Windows сообщила 66 085 478 400 доступных байт физической памяти. WGPU использовал Vulkan.

Во всех прогонах запускается один и тот же самостоятельный `LastLight.exe` и повторяется один маршрут с ускоренным движением. Внутреннее и выходное разрешение 1920×1080. Высокий профиль использует MSAA 4× и карту теней 2048². Низкий профиль использует один сэмпл, тени 1024² и меньший бюджет частиц. У каждой серии отдельный процесс и фиксированные шаги симуляции. Показанный полный восточный маршрут записан с более спокойным темпом передвижения.

Время кадра измерено от начала обработки ввода до чтения буфера RGB и включает CPU, GPU и копирование результата. Ожидание обновления монитора, видеокодирование и сторонняя запись в замер не включены. RAM — пиковый рабочий набор Windows для игрового процесса. VRAM — максимальный зафиксированный образец выделенной памяти WDDM для этого PID. Она опрашивалась во время прогона, с числом образцов в сырых данных. Воспроизведение на GTX 1650 остаётся открытым.

Все шесть прогонов выполнили целевой p95 до 16,7 мс на этой конфигурации. Переход на низкий профиль уменьшил измеренную выделенную VRAM примерно на 63,5 МиБ. Диапазоны времени кадра на этом ПК перекрываются, поэтому устойчивого выигрыша по p95 в этой серии не измерено.
