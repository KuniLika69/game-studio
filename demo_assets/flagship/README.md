# Последний свет на набережной · ресурсы

Для главы созданы разновысотные корпуса, выделенные арки и оконные ниши, линии проводов, шкафы реле, таблички, светильники, контровой пар и подпорные элементы. Исходник мешей и рисунка вывесок находится в `build.py`. Он вызывает общий авторский сборщик GLB из «Мастерской после дождя» и использует отсканированные карты мостовой из preview. Базовые PBR-карты старого участка и деревянного пола остаются в прежних файлах, поэтому их можно сравнить отдельно.

Модели окружения и названия вымышлены. Референсы служили для подбора контраста, плотности деталей и масштаба. Механизмы и исходы описаны редактируемыми правилами проекта.
