# Записи шагов в «Мастерской после дождя»

Для каждой поверхности выделены три отдельных шага. Файлы преобразованы в моно PCM WAV 48 кГц, подровнены по пиковому уровню и плавно обрезаны по краям.

- Камень — [Hiking Boot Footsteps on Stone, Fission9](https://freesound.org/people/Fission9/sounds/521590/), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Источник — публичный HQ MP3 автора.
- Дерево — [Steps in wood floor, mikeask](https://opengameart.org/content/steps-in-wood-floor), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Источник — WAV автора.
- Вода — [Splashing Footsteps Shallow Water, ChristopherJngs](https://freesound.org/people/ChristopherJngs/sounds/861369/), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Источник — публичный HQ MP3 автора.
