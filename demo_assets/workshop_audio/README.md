# Звук «Мастерской после дождя»

`lida.wav` содержит оригинальную реплику сцены. Она синтезирована на этом ПК голосом Microsoft Irina Desktop через Windows SAPI и сохранена в PCM 16 бит, 22 050 Гц, моно. Длительность 10,798821 с. Звучание в игре использует встроенный WAV и пространственный микшер.

`lida-visemes.csv` содержит 120 событий `System.Speech.Synthesis.SpeechSynthesizer.VisemeReached`. Столбцы содержат время от начала реплики в миллисекундах, длительность события и номер виземы. Мастерская преобразует эти события в три канала GLB лица. Моргание, взгляд, брови и кивки слушателя заданы отдельно.

Щелчок защёлки движок синтезирует из трёх затухающих тонов. Он звучит в позиции ручки при подтверждённом контакте правой ладони.

## Диалог 0.23 у шлюза

В каталоге `flagship` голос Лиды — Microsoft Irina Desktop, 15,955 с. Кривая использует 170 событий SAPI. Две реплики Арсена синтезированы голосом Microsoft Pavel из установленного Windows OneCore, 5,646 и 5,909 с. Для Павла таблицы артикуляции получены из русских фонем текста и огибающей PCM. Оба голоса записаны офлайн в моно PCM16 22 050 Гц. Положение голоса относится к говорящему персонажу. Отдельные исходные WAV и таблицы встроены в движок как пример и сохраняются в сцене.

Для локальной сборки использованы установленные системные голоса Windows. Подтверждение условий для публичного распространения этих WAV остаётся открытым. [Описание системного синтезатора и голосов Windows](https://learn.microsoft.com/en-us/uwp/api/windows.media.speechsynthesis.speechsynthesizer)

Фон дождя и помещения, шорох ткани и дыхание после нагрузки синтезируются в аудиомикшере. Происхождение записанных шагов указано отдельно. [Шаги и авторство](steps/README.md)
