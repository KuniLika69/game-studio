# Карты поверхностей Robot Studio

Четыре набора используют карты Poly Haven под лицензией [CC0](https://polyhaven.com/license), уже включённые в каталог сцен проекта. `prepare.py` приводит цвет, нормали OpenGL и шероховатость к 1024 × 1024. Шероховатость записана в зелёный канал карты glTF.

- Лесная почва — [Forest Ground 06](https://polyhaven.com/a/forest_ground_06).
- Речная галька — [Dry River Pebbles](https://polyhaven.com/a/dry_river_pebbles).
- Городская мостовая — [Cobblestone Pavement](https://polyhaven.com/a/cobblestone_pavement).
- Старый кирпич — [Brick Wall 09](https://polyhaven.com/a/brick_wall_09).

Карты зачарованного камня строятся локально из зерна в редакторе.
